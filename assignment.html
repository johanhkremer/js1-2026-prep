🛸 Portal Pass Control

Citadel of Ricks har fått problem: fel personer smiter igenom portalerna. Ditt jobb är att bygga ett litet kontrollsystem som jobbar med objects och arrays.

Mål Filtrera, formatera och uppdatera data
Regel Mutera inte original-arrayen
Output console.log efter varje steg

📦 Startkod

Du får en lista med portalpass. Varje pass är ett object med nested data: inventory och address. 

// Klistra in startkoden i script.js:
const portalPasses = [ ... ]

✅ Del 1 — Namnlista (map)

Skapa en ny lista som bara innehåller name och dimension.

Format: Rick Sanchez (C-137)

🚨 Del 2 — Efterlysta (filter)

Filtrera fram alla som är isWanted: true.

  • Skriv ut antal efterlysta
  • Skriv ut deras namn

🛂 Del 3 — Approved list (filter)

En karaktär är godkänd om:

  • clearance >= 3
  • inventory.portalGun === true
  • isWanted === false

🪪 Del 4 — Passerkort (map + nested)

Omvandla Approved list till en ny lista med objekt: 

{
  id: 1,
  badge: "⭐️",
  crystals: 3
}

Krav:

  • badge får vara bara en ikon (t.ex. "⭐️")
  • crystals ska komma från inventory.crystals

🔎 Krav

  • Du ska använda map(), filter() och find()
  • Du ska använda dot-notation: character.address.city
  • Du får inte mutera portalPasses
  • Du ska logga resultatet efter varje steg
🧠

Tänk: data in → transformera → data ut. Du bygger ett litet “system”, inte bara en loop.

Hint: Börja med att skapa variabler för varje steg, typ step1, step2, osv.
