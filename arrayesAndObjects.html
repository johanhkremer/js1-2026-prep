Arrays & Objects

Array

En array är en lista med värden i en viss ordning. Du kommer åt saker i listan med index (platsnummer) som börjar på 0. Arrayer passar när ordningen spelar roll, t.ex. en lista med frukter.

Object

Ett object används för att beskriva en sak med egenskaper. Egenskaperna skrivs som nyckel: värde (t.ex. title, price, inStock). Du hämtar en egenskap med punktnotation (t.ex. product.title).

Varför båda?

Array och object löser olika problem: en array är bra för listor, men ett object är bättre när du vill att datan ska vara tydlig och självförklarande. Därför är det vanligt i frontend att använda arrayer med objekt (t.ex. en lista av produkter).
