JavaScript - logiska operatorer

Villkor med if / else

Med if kan vi låta programmet fatta beslut. Koden i blocket körs bara om villkoret är true. 

const age = 20;

if (age >= 18) {
  console.log("Du är myndig");
}

Om villkoret är false händer ingenting. Vill vi göra något annat använder vi else. 

const age = 15;

if (age >= 18) {
  console.log("Du är myndig");
} else {
  console.log("Du är inte myndig");
}

Hur det fungerar

  • if = kontrollerar ett villkor
  • Parentesen innehåller villkoret
  • Klamrarna innehåller kod som körs om villkoret är true
  • else körs om villkoret är false

Logiska operatorer

Logiska operatorer används för att kombinera flera villkor (true/false). De används ofta tillsammans med if.

&& (AND / OCH)

&& betyder att alla villkor måste vara true. 

const age = 20;
const hasTicket = true;

if (age >= 18 && hasTicket) {
  console.log("Du får komma in!");
}

|| (OR / ELLER)

|| betyder att det räcker att minst ett villkor är true. 

const isMember = false;
const hasCoupon = true;

if (isMember || hasCoupon) {
  console.log("Du får rabatt!");
}

! (NOT / INTE)

! vänder på ett boolean-värde. 

const isLoggedIn = false;

if (!isLoggedIn) {
  console.log("Du måste logga in först!");
}

Sammanfattning

  • if = gör något om villkoret är true
  • else = gör något annat om det är false
  • && = OCH
  • || = ELLER
  • ! = INTE
