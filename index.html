Arrayer & array-metoder

En array är en lista med värden. Istället för att skapa många variabler kan vi samla flera värden i en och samma struktur. Varje värde i en array har en position (index) som börjar på 0.

Arrayer används när vi vill lagra flera saker tillsammans - till exempel namn, produkter, poäng eller uppgifter. Vi kan hämta ett enskilt värde genom dess index eller arbeta med hela listan samtidigt.

Array-metoder

JavaScript har många inbyggda array-metoder som gör det enklare att arbeta med listor. Istället för att skriva avancerade loopar kan vi använda färdiga metoder för att:

  • Lägga till eller ta bort värden
  • Gå igenom varje element
  • Skapa en ny array baserad på en gammal
  • Filtrera fram vissa värden
  • Kontrollera om något finns i listan

Några vanliga metoder är push(), pop(), map(), filter() och forEach(). De hjälper oss att skriva renare och mer läsbar kod.

Viktigt att tänka på

Vissa array-metoder ändrar den ursprungliga arrayen (till exempel push()), medan andra skapar en ny array (till exempel map() och filter()). Det är viktigt att förstå skillnaden så att du inte råkar ändra data av misstag.

Arrayer och array-metoder är centrala i modern JavaScript och används hela tiden när vi jobbar med data, DOM-manipulation och interaktiva webbsidor.
