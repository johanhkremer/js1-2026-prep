Vad är JavaScript?

JavaScript är ett programmeringsspråk som gör webbsidor interaktiva. HTML beskriver strukturen, CSS beskriver utseendet och JavaScript beskriver beteendet (logiken).

Var körs JavaScript?

  • I webbläsaren (Chrome, Firefox, Edge) – för interaktivitet på sidan
  • På servern (Node.js) – för att bygga API:er och backend

Vad kan JavaScript göra?

  • Reagera på klick, tangenttryckningar och formulär
  • Ändra innehåll på sidan (text, klasser, element)
  • Validera input
  • Hämta data från API:er
  • Bygga hela webbapplikationer (t.ex. med React senare)

Hur “körs” JavaScript?

  • JavaScript körs rad för rad uppifrån och ned.
  • Det är dynamiskt typat – värden kan ha olika typer över tid.
  • Du felsöker oftast med Console i DevTools.

Hur kopplas JavaScript till HTML?

JavaScript kan skrivas direkt i en <script>-tagg eller länkas in som en extern fil (vanligast).
