# JavaScript 1 – Course Prep Repository

This repository contains **lecture material and walkthroughs** for the **JavaScript 1** course.

The purpose of this repo is to support live lessons by providing:
- Code examples used during lectures
- Step-by-step walkthroughs
- Demonstrations of JavaScript fundamentals

❗ **No assignments or graded tasks are included in this repository.**  
All exercises and examination tasks are distributed separately via the course platform.

## Structure

- Each lesson is organized in its **own branch**
- The `main` branch serves as a base reference
- Students are expected to **follow along during lectures**, not work independently from this repo

## Topics Covered

Depending on the lesson, content may include:
- JavaScript syntax and basics
- Variables and data types
- Conditions and loops
- Functions
- Arrays and objects
- Basic debugging and console usage
- Introduction to DOM manipulation

## How to Use This Repository

- Switch to the branch matching the current lesson
- Follow the code demonstrated during class
- Use the material as **reference**, not as a solution bank
